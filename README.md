# Sonora Web v3

Веб-плеер для GitHub Pages с облачной музыкальной библиотекой на Cloud.ru Evolution Object Storage.

## Что есть в v3

- PIN-экран (это только экран от случайного просмотра, не настоящая защита).
- Плеер: воспроизведение, пауза, следующий/предыдущий трек, перемешивание, повтор, перемотка и громкость.
- 10-полосный эквалайзер и пресеты.
- Облачная библиотека читается из публичного файла `tracks.json` в Cloud.ru.
- Треки из облака воспроизводятся по постоянным публичным URL.
- Локальные файлы можно по-прежнему добавить для текущего браузера/устройства. Они не загружаются в Cloud.ru и не синхронизируются.

## Архитектура выбранного простого варианта

- Сайт: GitHub Pages.
- Аудио и `tracks.json`: публичное чтение из бакета Cloud.ru `sonora-music`.
- Добавление и удаление облачных файлов: вручную через консоль Cloud.ru.
- Никаких Access Key / Secret Key в `index.html` нет и быть не должно.

**Важно:** публичная ссылка позволяет любому человеку, у которого она есть, скачать/слушать файл. PIN на GitHub Pages не защищает аудио и обходится технически.

## Настройка Cloud.ru

В бакете `sonora-music` должны лежать:
- `Nervi_Batarei.mp3` (или другие ваши аудиофайлы);
- `tracks.json` из этого архива.

Загрузите `tracks.json` в корень бакета. Его публичный адрес должен быть:

`https://global.s3.cloud.ru/sonora-music/tracks.json`

В `tracks.json` каждый элемент массива `tracks` должен содержать:
- `title` — название композиции;
- `artist` — исполнитель (можно пустую строку);
- `url` — полный публичный HTTPS URL аудиофайла.

Пример:

```json
{
  "tracks": [
    {
      "title": "Название композиции",
      "artist": "Исполнитель",
      "url": "https://global.s3.cloud.ru/sonora-music/file.mp3"
    }
  ]
}
```

Чтобы добавить облачный трек:
1. Загрузите аудиофайл в бакет через консоль Cloud.ru.
2. Скопируйте его постоянный публичный URL.
3. Добавьте запись в `tracks.json` и загрузите обновлённый `tracks.json` в бакет с заменой старого файла.
4. Обновите Sonora в браузере.

Чтобы удалить облачный трек:
1. Удалите объект в консоли Cloud.ru.
2. Удалите его запись из `tracks.json` и загрузите обновлённый файл.

Не вставляйте временные presigned URL с `X-Amz-*` в `tracks.json`: они истекают. Используйте постоянный публичный URL объекта.

## CORS в Cloud.ru

Для работы сайта и эквалайзера настройте CORS у бакета:

- Allowed origin: `https://bobbymakegames.github.io`
- Allowed methods: `GET`, `HEAD`
- Allowed headers: `*`
- Expose headers: `Accept-Ranges`, `Content-Length`, `Content-Range`, `ETag`
- Max age: `3600`

В поле Origin указывается домен без пути `/Sonora_Web`. Если используете собственный домен, добавьте и его.

Если аудио открывается прямой ссылкой, но не загружается в плеере, в первую очередь проверьте CORS. Прямое открытие URL в отдельной вкладке само по себе не проверяет CORS.

## Публикация на GitHub Pages

1. Распакуйте архив.
2. Замените `index.html` и `README.md` в корне репозитория файлами из папки `Sonora_Web-v3`.
3. В репозитории откройте **Settings → Pages** и проверьте публикацию из ветки `main`, папка `/ (root)`.
4. Дождитесь обновления GitHub Pages и откройте сайт.
5. После загрузки `tracks.json` в бакет обновите страницу Sonora.

## Ограничения

- В браузерном приложении нет безопасного способа загружать/удалять объекты в S3 без доверенного сервера или временных подписанных URL. Поэтому облачные загрузки/удаления выполняются через консоль Cloud.ru.
- Локальные файлы сохраняются в IndexedDB только в текущем профиле браузера.
- Облачный список — это `tracks.json`; автоматического сканирования бакета и автоматического обновления списка нет.
- PIN хранится в клиентском коде в виде SHA-256-хеша и не является настоящей аутентификацией.
